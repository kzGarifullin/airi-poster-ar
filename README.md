# AIRI Poster AR — книга и «Паруса»

Два интерактивных примера редактирования русского текста. Камера распознаёт обложку и показывает соответствующее видео поверх изображения. Также доступен обычный просмотр видео.

## GitHub Pages

В Settings → Pages выбрать Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)** и нажать Save.

После публикации адрес сайта: https://kzgarifullin.github.io/airi-poster-ar/

Открыть сайт в Safari или Chrome на телефоне, нажать «Открыть AR-камеру», разрешить камеру и навести на книгу либо «Паруса» на постере. Для первого теста можно наводить на постер на экране компьютера.

## Мишени

- 0: `01-book.jpg` (обложка `strugatskie_names_0.jpg`, взята из обновлённого poster_final) → `01-book.mp4`
- 1: `02-sails.jpg` → `02-sails.mp4`

`targets.mind` скомпилирован в указанном порядке MindAR 1.2.5. Изображения взяты из финальной версии постера. Сам файл постера в репозитории отсутствует.

Камера обрабатывается локально в браузере; приложение не отправляет кадры на сервер. Библиотеки включены в `vendor/`, лицензии сохранены. Подход к анимации постеров вдохновлён arspace: https://github.com/emb-ai/arspace.

Проверены компиляция мишеней, локальные ссылки, синтаксис JS и HTTP-ресурсы. Проверка AR камерой реального телефона ещё требуется.
